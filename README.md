FNP Sales Analysis & Interactive Excel Dashboard

Project Overview:This project focuses on analyzing FNP sales data using Microsoft Excel to identify sales trends, customer behavior, product performance, and overall business performance.
The project includes data cleaning, data analysis, PivotTables, charts, and an interactive Excel dashboard to present key business insights in an easy-to-understand format.
Project Objective:The main objective of this project is to transform raw sales data into meaningful business insights using Excel.

The analysis focuses on:
* Sales performance
* Product performance
* Customer behavior
* Order trends
* Revenue analysis
* Identifying important business trends

Tools & Technologies Used
* Microsoft Excel
* Power Query
* PivotTables
* PivotCharts
* Excel Formulas
* Slicers
* Power Pivot
* Data Cleaning & Transformation
* Data Visualization

Project Workflow
Raw Data → Data Cleaning → Data Transformation → Data Analysis → PivotTables → Dashboard → Business Insights**

1.Data Preparation
* Imported the raw FNP sales dataset into Excel.
* Checked the dataset for missing values and inconsistencies.
* Cleaned and transformed the data using Excel and Power Query.
* Prepared the data for analysis and visualization.
2. Data Analysis
Used Excel features such as:
* PivotTables
* Excel formulas
* Power Pivot
* Pivot Charts
* Slicers
to analyze sales and business performance.
3.Dashboard Development
Created an interactive Excel dashboard containing:
* Key Performance Indicators (KPIs)
* Sales analysis
* Product analysis
* Customer and order analysis
* Charts and visualizations
* Interactive slicers

Dashboard
The final dashboard provides an interactive view of the FNP sales data and allows users to explore different aspects of business performance using filters and slicers.

Key Insights
The analysis helped identify:
* Overall sales performance and trends.
* Top-performing products and categories.
* Customer and order patterns.
* Sales distribution across different segments.
* Important trends that can support business decision-making.
